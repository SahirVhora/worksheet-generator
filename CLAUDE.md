# CLAUDE.md — worksheet-generator

Single-file HTML/CSS/JS worksheet generator for UK primary school kids (Reception to Year 6).

## Live site
sahirvhora.github.io/worksheet-generator

## Rules
- Single `index.html` — all resources in one file
- Dark theme, Nunito font, mobile-responsive
- No external dependencies, no build step
- Don't change the worksheet generation logic (math operators, question types) without asking

## Commands
- No test suite — open index.html in browser to verify
- Push to main → GitHub Actions auto-deploys Pages
